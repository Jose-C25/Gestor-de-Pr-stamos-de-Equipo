# Préstamos Lab — 0902-23-11034

## Requisitos Previos
Tener instalado Node.js (v18 o superior).

## Pasos para instalar y ejecutar
1. Clonar el repositorio.
2. Abrir la terminal en la carpeta del proyecto y ejecutar `npm install`.
3. Ejecutar el comando unificado: `npm run dev`.
4. El frontend estará disponible en `http://localhost:5173` y la API en `http://localhost:3001`.
